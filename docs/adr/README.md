# ADR — Architecture Decision Records

Decisiones de arquitectura que no encajan en una spec de feature.

## Formato

```
NNN-titulo-corto.md
```

Plantilla mínima:

```markdown
# ADR-NNN: Título

## Estado
accepted | proposed | deprecated

## Contexto
...

## Decisión
...

## Consecuencias
...
```

Ejemplo pendiente: elegir stack (Next.js vs alternativa), proveedor IA, almacenamiento local vs DB.
